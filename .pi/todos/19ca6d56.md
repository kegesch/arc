## Problem
`arc add use_case` and `arc add entity_model` don't accept structured fields via CLI flags (actors, preconditions, main_flow, acceptance_criteria, entities). The only way to set them is by hand-editing the YAML file after creation.

## Steps
1. Add CLI flags for use_case structured fields (--actors, --preconditions, --acceptance-criteria, --main-flow)
2. Add CLI flags for entity_model structured fields (--entities or --body-file for complex YAML)
3. Then dogfood: create use cases and entity models for arc itself

## Requirements
- R-039: CLI flags for use_case structured fields (NEW)
- R-040: CLI flags for entity_model structured fields (NEW)
