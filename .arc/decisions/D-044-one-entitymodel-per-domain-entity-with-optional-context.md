title: "One entity_model per domain entity with optional context"
status: accepted
date: 2026-05-30
driven_by: [R-036]
---

Each entity_model describes a single domain entity (e.g., EM-001=Entity, EM-002=Edge). An optional context groups them into a bounded context. This gives finer granularity for code generation and traceability per entity.
